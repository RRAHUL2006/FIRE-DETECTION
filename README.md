The AI-Based Fire Detection System is an intelligent real-time surveillance and safety monitoring solution designed to automatically detect fire and smoke using Artificial Intelligence, Computer Vision, and Deep Learning technologies.

The system uses CCTV cameras, IP cameras, webcams, or uploaded video footage to continuously monitor environments and identify fire or smoke at an early stage. Using advanced object detection models such as YOLOv8 and OpenCV, the system can accurately detect flames and smoke in real time and immediately trigger emergency alerts.

The solution is designed to improve fire safety, reduce response time, prevent property damage, and enhance smart surveillance systems in industries, offices, warehouses, public places, and smart city environments.
